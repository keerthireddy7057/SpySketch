How To Play

  1. Create a room and share the room code with friends.
  2. The host chooses a category and round time.
  3. When the round starts, one player becomes the spy sketcher.
  4. Normal players see the secret word. The spy sketcher sees only ???.
  5. Everyone draws on the same canvas without revealing too much.
  6. Vote for the player who seemed suspicious.
  7. If the group catches the spy sketcher, artists score. If not, the spy sketcher scores.
